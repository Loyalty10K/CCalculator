# CCalculator
A simple command-line calculator written in C. It takes two numbers and an operation (+, -, *, /) and prints the result.

## How to run

Compile the program with gcc, then run the resulting executable.

gcc calculator.c -o calculator
./calculator

## Example

Please enter first number: 5
Please enter second number: 3
Please enter the operation you would like (+, -, *, /): +
Your result is: 8
